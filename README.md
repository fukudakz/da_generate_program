## 学会プログラム HTML 生成

セッションと発表の CSV から、プログラムページ（HTML）を作ります。  
実行するのは `generate_program_html.py` です。大会名は `input/conference_name.txt` で決まります。

---

### 1. ディレクトリ構成

- `generate_program_html.py`  
  プログラム HTML を生成するスクリプト。

- `input/`  
  手で編集する入力です。
  - `session.csv`  
    セッション一覧（日時・会場・セッション名など）。
  - `talk.csv`  
    各セッションに属する発表一覧。
  - `conference_name.txt`  
    HTML の `<title>` とページ先頭の `h1` に出す大会名。

- `output/`
  - `program.html`  
    生成されたプログラムページ。

---

### 2. 前提環境

- Python 3.x（標準ライブラリのみ）
- 文字コードは UTF-8

---

### 3. 入力ファイル仕様

#### 3-1. `input/session.csv`

ヘッダ行付きのカンマ区切り CSV です。

必須カラム:

- `セッションID`
- `セッション名`
- `日付` … 例: `2026-11-7`
- `時間` … 例: `10:10〜11:50`
- `座長`（空でも可）
- `会場` … 例: `21号館312`。番号の無い会場名（例: `後日公開`）も可

`セッションID` は文字列として扱い、`talk.csv` の `所属するセッション` と対応づけます。

#### 3-2. `input/talk.csv`

必須カラム:

- `発表ID`
- `easychair_paper_ID`（空でも可）
- `所属するセッション` … `session.csv` の `セッションID`
- `著者`
- `タイトル`

任意カラム:

- `URL`（空でも可）… あるとタイトルがリンクになる。別タブで開く。見出しと同じ青なので、下線を付けて区別する
- `学生発表` … `1` のとき、タイトル先頭に「学生」の印を付ける。優秀学生発表賞の選考対象。`0` または空は印なし

同じセッション ID の発表は、そのセッションの下に `発表ID` 順で並びます。

#### 3-3. `input/conference_name.txt`

最初の空でない行が大会名です。

例:

```text
デジタルアーカイブ学会 第11回研究大会 プログラム
```

この文字列が `<title>` とページ先頭の `<h1>` になります。

---

### 4. 使い方

このディレクトリで次を実行します。

```bash
python3 generate_program_html.py
```

`output/program.html` ができます。ブラウザで開くとプログラムが表示されます。

WordPress に載せるときは、カスタム HTML ブロックに `page-wrap` の `div` ごと貼ります。中の `<style>` も含めてください。ビジュアルエディタに貼ると、表のスタイルがテーマに上書きされることがあります。

---

### 5. 生成される HTML

1. **ページタイトル**  
   `conference_name.txt` を `<title>` と `<h1>` に出します。

2. **タイムテーブル**  
   日付ごとに表を作ります。
   - 行: 時間帯（開始時刻の順）
   - 列: 会場。部屋番号の昇順で、番号が無い会場は右端
   - セル: その時間・会場のセッション名（複数なら改行）。下の「プログラム詳細」へのページ内リンク

3. **プログラム詳細**  
   日付、時間帯のあと、各セッションに次を出します。
   - 会場
   - セッション名（アンカーは `id="session-<セッションID>"`）
   - 座長（ある場合）
   - 発表タイトルと著者。`URL` があるタイトルは下線付きリンク。`学生発表` が `1` のタイトルには「学生」の印

   学生発表が1件でもあると、ページ末尾に「※学生は優秀学生発表賞の選考対象です」と出します。

4. **見た目**  
   スタイルは `page-wrap` 内の `<style>` と、表・リンク・学生印の `style` 属性にあります。WordPress のテーマより表の枠線・余白・中央揃えが優先されるようにしてあります。見出し（`h3`、`h4`、セッション名）とリンクは同じ青で、リンクだけ下線があります。タイムテーブルのセッション名も下線付きです。

---

### 6. 直し方

- 大会名は `input/conference_name.txt` の1行目を書き換えてから、スクリプトを再実行します。
- セッションと発表は `input/session.csv` と `input/talk.csv` を編集してから、再実行します。
- 発表のリンクは `talk.csv` の `URL`、学生印は `学生発表` を編集してから再実行します。
- 配色、余白、リンクの下線は `generate_program_html.py` の CSS と `LINK_STYLE` を編集します。`style` 属性側も合わせて変えないと、WordPress で `<style>` が削られたときに下線が残らないことがあります。

---

### 7. 注意

- CSV は UTF-8 で保存します。
- `セッションID` と `所属するセッション` は一致させます。
- `時間` は `HH:MM〜HH:MM` です。区切りは `〜` または `～` を想定し、開始時刻で並べます。
- `学生発表` は `1` だけが印の対象です。
